在线检索版 · 部署与分享说明
============================

【这是什么】
《2026淮北市规上制造业企业产需信息汇编》在线检索版。特点：
· 浏览器打开就能用，电脑/手机都行；
· 输入企业名称、产品、原材料、联系人等关键词 → 实时列出命中页码；
· 点击结果即跳转到对应页面，并高亮所有命中位置；
· 每个页面都有独立链接（点击"复制本页链接"），可直接分享给同事定位到某页；
· "企业名录"按钮：全书 491 家企业一键筛选、点击直达；
· "缩略图"按钮：全书 527 页总览。

【目录结构】（不要改动文件名与层级）
  index.html      网页主文件
  data.js         全书文字索引（搜索用）
  img/            527 张页面图片（0000.jpg ~ 0526.jpg）
  部署说明.txt    本文件

------------------------------------------------------------
一、部署到网上（推荐，做完就有可分享的链接）
------------------------------------------------------------
方案 A：腾讯云 COS / 阿里云 OSS 静态网站（国内速度最快，推荐正式发布）
  1. 登录腾讯云 → 对象存储 COS → 新建存储桶（地域选就近，如南京/上海）；
  2. 访问权限选「公有读私有写」；
  3. 进入存储桶 → 上传文件 → 把本目录下所有文件（含 img 文件夹）上传；
  4. 开启「静态网站」功能，得到访问地址（形如
     https://xxx.cos-website.ap-nanjing.myqcloud.com/ ），
     也可以绑定自己的域名；
  5. 把这个链接发到群里，任何人点开就能搜索。
  费用：存储约 100MB，流量按访问量计，日常使用每月几毛到几元。

方案 B：Gitee Pages（免费，国内访问速度不错）
  1. 注册并完成实名认证：https://gitee.com
  2. 新建仓库（公开），如 chanshu；
  3. 用网页"上传文件"把本目录全部文件上传（img 文件夹整体拖入）；
  4. 仓库 → 服务 → Gitee Pages → 部署分支选 master，目录选根目录 → 启动；
  5. 得到链接 https://你的用户名.gitee.io/chanshu/ ，分享即可。
  注意：Gitee 免费版 Pages 每次更新文件后需在 Pages 页点"更新"。

方案 C：GitHub Pages / Netlify / Vercel（免费，海外节点，国内速度一般）
  · GitHub：新建仓库 → 上传文件 → Settings → Pages → 选 main 分支根目录 → 保存；
  · Netlify/Vercel：注册后直接把本目录（或 zip）拖进网页，几十秒即得链接。

方案 D：单位已有服务器 / 虚拟主机
  用 FTP 或宝塔面板把本目录整体传到网站目录（如 /www/wwwroot/chanshu/），
  访问 http://你的域名/chanshu/ 即可。

------------------------------------------------------------
二、分享与使用小贴士
------------------------------------------------------------
· 分享整个网站的链接：大家打开后自己搜关键词；
· 分享某一页：打开到该页 → 点"复制本页链接" → 发出去，对方点开直接定位该页；
  （链接形如 https://你的网址/#p=330 ，p 后面的数字是图号）
· 手机使用：微信里打开链接 → 右上角"在浏览器打开"，体验更顺；
· 可把链接生成二维码贴在材料上，扫码即用。

------------------------------------------------------------
三、常见问题
------------------------------------------------------------
Q：为什么不用 PDF 直接嵌进网页？
A：原 PDF 是纯图片版（无文字层）且 330MB，浏览器加载慢且无法搜索。
   本方案用页面图片 + 文字索引，打开快、能搜索、能高亮、能分享定位。

Q：搜索不到某个词？
A：索引来自全书识别文字，个别生僻字可能有偏差，建议用企业名核心 2~4 个字。

Q：手机上图片加载慢？
A：首次浏览会按需加载当前页图片，之后浏览器有缓存；建议 Wi-Fi 下使用。

Q：想改标题/加单位 logo？
A：直接改 index.html 顶部 <h1> 文本即可；需要我改也可以说。
